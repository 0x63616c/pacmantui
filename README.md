# pacmantui

Pac-Man in your terminal — real pixel graphics inside [Ghostty](https://ghostty.org)
via the [Kitty Graphics Protocol](https://sw.kovidgoyal.net/kitty/graphics-protocol/).

**Status: under construction.** See `docs/plan/PROGRESS.md`.

Gameplay follows [The Pac-Man Dossier](https://pacman.holenet.info/) (Jamey Pittman)
as the source of truth for classic-mode mechanics.
